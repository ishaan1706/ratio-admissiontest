# Desmos on Digital SAT Math

The built-in calculator is available throughout Math. Practice in [Bluebook](https://satsuite.collegeboard.org/practice/practice-tests/bluebook) to learn where controls sit on test day. For extra rehearsal, use the [Desmos testing calculator](https://www.desmos.com/testing/cb-sat/graphing). Review [College Board's live calculator policy](https://satsuite.collegeboard.org/sat/what-to-bring-do/calculator-policy) before bringing a device.

| Goal | Enter | Read and check |
|---|---|---|
| Solve an equation | Type `y=3(x-2)` and `y=15` on separate lines. | Select the intersection (7, 15). The answer to “what is x?” is 7, not 15. Check by substitution. |
| Solve a linear system | Type `2x+y=17` and `x-y=1`. | Intersection (6, 5) satisfies both. Parallel lines with different intercepts do not intersect; identical lines share all points. |
| Find roots or a vertex | Enter `y=(x-2)^2-9`. | Roots are −1 and 5; vertex is (2, −9). For minimum output use −9. Zoom out if needed, and check by factoring or using vertex form. |
| Inspect an inequality | Enter `y<2x+1`. | The shaded side works. The dashed boundary itself does not; test (0, 0) and do not round an integer feasibility question the wrong way. |
| Enter exact fractions | Use `(x+2)/3` with parentheses. | Do not type `x+2/3` for the same expression. If the graph displays an approximate value, prefer a fitting exact fraction for SPR when possible. |
| Calculate a line of best fit | Make a table with columns `x_1` (1, 2, 3) and `y_1` (4, 6, 8); enter `y_1 ~ m x_1 + b`. | The regression should yield m = 2 and b = 2. Use tilde rather than equals. Use the model specified in the question, not a regression you chose just because it fits. |
| Use a parameter | Enter `y=ax+1` and make a slider for a. | Moving a changes only the slope. For a line through (4, 9), solve 9 = 4a + 1 exactly; the slider illustrates, not proves, a = 2. |

**Do it without a graph when** a one-step calculation is faster, exact form is the point, the key is units, or the question is about study design. Matching graphs at a few values does not prove equivalence. A rounded intersection may hide distinct values or an excluded endpoint; check original equations and domain restrictions.

**Two-minute drill:** Graph an equation; identify the requested coordinate; verify it exactly; then solve one comparable item without a graph. Use the bank's Desmos-friendly filter for suitable practice, not as a signal that the calculator is required.
