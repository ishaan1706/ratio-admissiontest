# ESAT Formula and Fact Sheets

No formula sheet is provided in the ESAT unless a question gives a formula. Learn everything below until you can recall it instantly. Original material based on the official ESAT Content Specification; not official UAT-UK material.

## Mathematics 1

| Topic | Formula / fact |
|---|---|
| Quadratic formula | x = [−b ± √(b² − 4ac)] / 2a |
| Completing the square | ax² + bx + c = a(x + b/2a)² + c − b²/4a |
| Difference of two squares | a² − b² = (a + b)(a − b) |
| Indices | aᵐ × aⁿ = aᵐ⁺ⁿ; (aᵐ)ⁿ = aᵐⁿ; a⁰ = 1; a⁻ⁿ = 1/aⁿ; a^(m/n) = (ⁿ√a)ᵐ |
| Surds | √a × √b = √(ab); rationalise 1/(a + √b) by multiplying by (a − √b) |
| Percentage change | new = old × (1 ± r/100); reverse: old = new ÷ multiplier |
| Compound growth | A = P(1 + r/100)ⁿ |
| Straight line | y = mx + c; m = (y₂ − y₁)/(x₂ − x₁); perpendicular gradients multiply to −1 |
| Midpoint, distance | ((x₁ + x₂)/2, (y₁ + y₂)/2); √[(x₂ − x₁)² + (y₂ − y₁)²] |
| Circle at origin | x² + y² = r² |
| nth term | linear: a + (n − 1)d; quadratic: second difference ÷ 2 gives the n² coefficient |
| Pythagoras | a² + b² = c² |
| Trigonometry | sin = O/H, cos = A/H, tan = O/A |
| Sine rule | a/sin A = b/sin B = c/sin C |
| Cosine rule | a² = b² + c² − 2bc cos A |
| Triangle area | ½ab sin C |
| Exact values | sin 30° = ½, sin 45° = √2/2, sin 60° = √3/2; cos 30° = √3/2, cos 45° = √2/2, cos 60° = ½; tan 30° = 1/√3, tan 45° = 1, tan 60° = √3 |
| Circle | C = 2πr; A = πr²; arc = (θ/360) × 2πr; sector = (θ/360) × πr² |
| Volumes | prism: area × length; cylinder: πr²h; cone: ⅓πr²h; sphere: (4/3)πr³; pyramid: ⅓ × base × h |
| Surface areas | sphere: 4πr²; cone curved surface: πrl |
| Trapezium | ½(a + b)h |
| Polygons | interior angle sum = (n − 2) × 180°; exterior angles sum to 360° |
| Similarity | lengths × k, areas × k², volumes × k³ |
| Circle theorems | angle at centre = 2 × angle at circumference; angles in the same segment equal; angle in a semicircle = 90°; opposite angles of a cyclic quadrilateral sum to 180°; tangent ⊥ radius; alternate segment theorem; two tangents from a point are equal |
| Probability | P(A or B) = P(A) + P(B) − P(A and B); independent: P(A and B) = P(A)P(B); conditional: P(A given B) = P(A and B)/P(B) |
| Counting | n! arrangements; ordered selections n × (n − 1) × … |
| Histograms | frequency = frequency density × class width |
| Bounds | upper bound of a ÷ b = upper a ÷ lower b |
| Speed-time graphs | gradient = acceleration; area = distance |

## Mathematics 2 (in addition to Mathematics 1)

| Topic | Formula / fact |
|---|---|
| Discriminant | b² − 4ac > 0: two real roots; = 0: one repeated root; < 0: no real roots |
| Factor theorem | f(a) = 0 ⇔ (x − a) is a factor; remainder on dividing by (x − a) is f(a) |
| Arithmetic series | uₙ = a + (n − 1)d; Sₙ = n/2 [2a + (n − 1)d] = n/2 (first + last) |
| Geometric series | uₙ = arⁿ⁻¹; Sₙ = a(1 − rⁿ)/(1 − r); S∞ = a/(1 − r) for |r| < 1 |
| Sums | Σr (r = 1 to n) = n(n + 1)/2 |
| Binomial | (a + b)ⁿ = Σ ⁿCᵣ aⁿ⁻ʳ bʳ; ⁿCᵣ = n!/[r!(n − r)!] |
| Circle | (x − a)² + (y − b)² = r²; complete the square to find centre and radius |
| Radians | π rad = 180°; arc = rθ; sector = ½r²θ |
| Identities | sin²x + cos²x = 1; tan x = sin x / cos x |
| Trig graphs | sin and cos period 2π, tan period π; y = a sin(bx): amplitude |a|, period 2π/b |
| Logarithms | log(ab) = log a + log b; log(a/b) = log a − log b; log aⁿ = n log a; logₐa = 1; logₐ1 = 0; aˣ = b ⇔ x = logₐb |
| Differentiation | d/dx (xⁿ) = nxⁿ⁻¹; tangent: y − y₁ = m(x − x₁); normal gradient = −1/m |
| Stationary points | dy/dx = 0; d²y/dx² > 0 minimum, < 0 maximum; if zero, check the sign of dy/dx either side |
| Integration | ∫xⁿ dx = xⁿ⁺¹/(n + 1) + c (n ≠ −1); area = ∫ₐᵇ y dx (take care below the axis) |
| Area between curves | ∫ (upper − lower) dx between intersection points |
| Transformations | f(x) + a: up a; f(x + a): left a; af(x): vertical stretch ×a; f(ax): horizontal stretch ×1/a; −f(x): reflect in x-axis; f(−x): reflect in y-axis |

## Physics

Use g = 10 N/kg (m/s²) unless told otherwise.

| Topic | Equation |
|---|---|
| Charge | Q = It |
| Ohm's law | V = IR |
| Power | P = IV = I²R = V²/R |
| Energy | E = QV = Pt = IVt |
| Resistors | series: R = R₁ + R₂ + …; parallel: 1/R = 1/R₁ + 1/R₂ + … |
| Potential divider | V₂ = V × R₂/(R₁ + R₂) |
| Motor effect | F = BIL (wire ⊥ field) |
| Transformer (ideal) | Vₚ/Vₛ = Nₚ/Nₛ; VₚIₚ = VₛIₛ |
| Speed | v = d/t; a = (v − u)/t |
| SUVAT | v = u + at; s = ut + ½at²; v² = u² + 2as; s = ½(u + v)t |
| Newton's second law | F = ma; F = Δp/Δt |
| Weight | W = mg |
| Momentum | p = mv; conserved in collisions and explosions |
| Hooke's law | F = kx; elastic energy E = ½kx² |
| Work | W = Fd (in the direction of the force) |
| Kinetic energy | Eₖ = ½mv² |
| Gravitational potential energy | ΔEₚ = mgΔh |
| Power | P = E/t = W/t |
| Efficiency | useful output ÷ total input (× 100%) |
| Density | ρ = m/V |
| Pressure | p = F/A; in a fluid p = hρg |
| Gas at constant temperature | p₁V₁ = p₂V₂ |
| Specific heat capacity | ΔE = mcΔθ |
| Specific latent heat | E = mL |
| Waves | v = fλ; T = 1/f |
| Reflection | angle of incidence = angle of reflection (measured from the normal) |
| Radioactive decay | alpha: A − 4, Z − 2; beta-minus: A same, Z + 1; gamma: no change. After n half-lives, fraction remaining = (½)ⁿ |
| Electromagnetic spectrum (increasing frequency) | radio, microwave, infrared, visible, ultraviolet, X-ray, gamma |
| Cost of electricity | energy (kWh) = power (kW) × time (h); cost = kWh × price |

## Chemistry

| Topic | Formula / fact |
|---|---|
| Moles | n = m/Mr; number of particles = n × 6.0 × 10²³ |
| Gas volume at rtp | V (dm³) = n × 24 |
| Concentration | c (mol/dm³) = n/V (dm³); 1 dm³ = 1000 cm³ |
| Percentage yield | actual ÷ theoretical × 100 |
| Atom economy | Mr of desired product ÷ total Mr of reactants × 100 |
| Empirical formula | divide mass % by Ar, then by the smallest, then scale to whole numbers |
| Calorimetry | q = mcΔT; ΔH = −q/n (exothermic if temperature rises) |
| Bond energies | ΔH = Σ(bonds broken) − Σ(bonds made) |
| pH | each tenfold change in [H⁺] changes pH by 1 |
| Oxidation states | elements 0; O usually −2; H usually +1; Group 1 +1; Group 2 +2; sum = charge |
| Redox | OIL RIG: oxidation is loss of electrons, reduction is gain |
| Electrolysis (aqueous) | cathode: metal if less reactive than hydrogen, otherwise H₂; anode: halogen if halide concentrated, otherwise O₂ |
| Rf | distance moved by spot ÷ distance moved by solvent front |
| Le Chatelier | the equilibrium shifts to oppose a change (pressure favours fewer gas moles; heating favours the endothermic direction) |
| Reactivity series | K, Na, Ca, Mg, Al, (C), Zn, Fe, (H), Cu, Ag, Au |
| Homologous series | alkanes CₙH₂ₙ₊₂; alkenes CₙH₂ₙ; alcohols CₙH₂ₙ₊₁OH; carboxylic acids Cₙ₋₁H₂ₙ₋₁COOH |
| Ester naming | alcohol part first, acid part second (ethanol + propanoic acid → ethyl propanoate) |
| Flame tests | Li⁺ crimson, Na⁺ yellow, K⁺ lilac, Ca²⁺ orange-red, Cu²⁺ green |
| Hydroxide precipitates | Cu²⁺ blue, Fe²⁺ green, Fe³⁺ brown, Al³⁺/Ca²⁺/Mg²⁺ white (Al(OH)₃ dissolves in excess) |
| Anion tests | carbonate: acid gives CO₂ (limewater milky); sulfate: acidified BaCl₂ gives white precipitate; halides: acidified AgNO₃ gives white (Cl⁻), cream (Br⁻), yellow (I⁻) |
| Gas tests | H₂ squeaky pop; O₂ relights a glowing splint; CO₂ limewater milky; Cl₂ bleaches damp litmus; NH₃ turns damp red litmus blue |

## Biology: key facts

| Topic | Fact |
|---|---|
| Aerobic respiration | glucose + oxygen → carbon dioxide + water |
| Anaerobic respiration | animals: glucose → lactic acid; yeast and plants: glucose → ethanol + carbon dioxide |
| Photosynthesis | carbon dioxide + water → glucose + oxygen (light, chlorophyll) |
| Limiting factors | light intensity, CO₂ concentration, temperature |
| Base pairing | A–T, G–C; %A = %T, %G = %C |
| Genetic code | triplet of bases per amino acid; stop codons code for none |
| Mitosis | 2 identical diploid cells; growth, repair, asexual reproduction |
| Meiosis | 4 genetically different haploid cells; gametes |
| Monohybrid ratios | Aa × Aa → 3 : 1 phenotypes (1 : 2 : 1 genotypes); Aa × aa → 1 : 1 |
| Heart pathway | vena cava → right atrium → right ventricle → pulmonary artery → lungs → pulmonary vein → left atrium → left ventricle → aorta |
| Cardiac output | stroke volume × heart rate |
| Blood glucose | high → insulin (pancreas) → glucose to glycogen; low → glucagon → glycogen to glucose |
| Water balance | dehydrated → more ADH → more water reabsorbed in collecting ducts → concentrated urine |
| Menstrual hormones | FSH (follicle), LH (ovulation), oestrogen (lining builds), progesterone (lining maintained) |
| Enzymes | lipase: fats → fatty acids + glycerol; protease: proteins → amino acids; amylase: starch → sugars |
| Population estimate | N = (n₁ × n₂)/m (mark–release–recapture) |
| Magnification | magnification = image size ÷ actual size |
| Xylem / phloem | xylem: dead, lignified, water and minerals up; phloem: living, sugars both ways (translocation) |
